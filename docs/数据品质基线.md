# 数据品质基线：新增事实的宾语

> **这是一次测量快照，不是验收标准，也不是待办清单。**
> 数字随数据增长而变化。重测时整份覆盖，不要往后累积。

- 测量时间：2026-11-22
- 对象库：`devinsight`（Docker `pgvector/pgvector:pg16`）
- 口径：`retracted_at IS NULL` 的存活事实

## 测量方法

```sql
select subject_id, predicate, array_agg(object_text order by object_text) as objects
from fact_claims where retracted_at is null
group by 1,2 having count(*) > 1 order by 2;
```

「同主语、同谓词、多宾语」共 **54 组**。本次人工复核了后半段 **44 组**，前约 10 组因 psql 分页未截入，基线尚不完整。

多值谓词出现多宾语本身是正常的。逐组判断后分三类。

| 谓词 | 组数 | 性质 |
|---|---|---|
| released | 16 | 重灾区，一半不是多值 |
| benchmark | 14 | 一半是误用 |
| released_version | 4 | 2 组是已知同物异写 |
| open_sourced | 4 | 2 组异写 |
| discontinued / funded / partnered_with | 各 2 | 异写或正常 |

## 一、真多值（约 20 组，正常）

多平台版本、多产物、多合作方。谓词本来就该有多个宾语。

- `{Android app, browser version, iOS app}`
- `{Coppice Linux 版, Coppice macOS 版}`
- `英伟达` 的 6 个 `partnered_with` 合作方

## 二、同一实体多种写法（约 13 组，库层挡不住）

```
2.7亿元回购专项贷款        / 2.7亿元回购专项贷款额度
Astra                      / GPT-6.2 Astra
《2026年11月金融稳定评估报告》/ 2026年11月金融稳定评估报告
Reflektor GitHub 仓库      / GitHub 上的 reflektor 仓库      ← 语序也变了
IPO / IPO 募资 / 首次公开募股
AI chip sales to China     / 对华 AI 芯片销售
textbook collection and resources / 教材合集与配套资源
Microsoft Azure            / Microsoft Azure 版
Reno17系列                 / OPPO Reno17系列
Wolfenstein 3D Amiga 500 版 / …移植版
43 reusable Agent Skills   / Agent Skills
```

唯一约束按 `object_text` 精确匹配，`object_entity_id` 虽存在但未参与，所以这类写法差异一律放过。

## 三、谓词误用（约 6 组，宾语不是该谓词该有的东西）

```
Metacritic / Metascore     ← 评分聚合站，不是 benchmark
blinded judges panel       ← 评审团，不是基准
LLM judges panel
leaderboard                ← 榜单
Alder Lake                 ← CPU 代号，那是测试平台不是被测基准
30 个库                    ← 数量，不是产物名
```

`released` 那组最典型：`{30 个库, SQLite 兼容数据库引擎, Word/Excel/PowerPoint 读写器, 确定性物理游戏引擎, 自带着色器编译器的 GPU 栈}`，四个真产物混进一个数量。模型把原文那一段列举整段塞了进去。

## 库层为何挡不住

| 缺口 | 后果 |
|---|---|
| `predicate` 是裸 `text`，无 CHECK、无谓词表外键 | 谓词不合规只能靠 `SPECS` 在抽取入口拦，直写 SQL 可绕过 |
| 无 `object_type` 列 | 形状检查（② 档）只在抽取时做，事后无法复查 |
| 唯一约束用 `object_text` 而非 `object_entity_id` | 同一实体的不同写法永远不撞 |

这与「删掉 `license` 类型让错误写不出来」的思路相反：那边让错误写不出来，这边是错误写得出来、只是没人写。

## 已知待观察
